# CONTEXT.md Format

`CONTEXT.md` is a glossary only. No implementation details. No specs. No scratch notes.

## Template

```markdown
# Domain Glossary

## <Term>

**Meaning:** ...

**Also known as:** ...

**Not to be confused with:** ...

**Used in:** ...
```

## Rules

- Define one term per section.
- Distinguish each term from similar terms.
- Include "not to be confused with" for overloaded words.
- Update inline as terms resolve.
- Never paste code, file paths, or implementation decisions.
