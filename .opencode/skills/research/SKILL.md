# Research

Spin up a background subagent so you keep working while it reads.

Its job:

1. Investigate the question against **primary sources** — official docs, source code, specs, first-party APIs — not secondary write-ups.
2. Write the findings to a single Markdown file, citing each claim's source.
3. Save it where the repo already keeps such notes; if there is no convention, put it somewhere sensible and say where.

When the subagent returns, surface the file path and the headline findings.
