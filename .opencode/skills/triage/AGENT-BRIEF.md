# Agent Brief Template

Use this template when moving an issue or PR to `ready-for-agent`.

```markdown
## Agent Brief

### Goal
One sentence: what the agent is building or fixing.

### Background
The minimum context needed: user pain, system area, and any decisions already made.

### Acceptance Criteria
- [ ] Criterion 1
- [ ] Criterion 2
- [ ] Criterion 3

### Seams
The public interfaces where tests should live.

### Out of Scope
What this ticket does not cover.

### Notes
Links to prototypes, ADRs, or prior discussions.
```

Keep the brief under 400 words. Avoid file paths and code snippets unless they encode an irreversible decision.
