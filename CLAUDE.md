# Claude Code project guidance

Read `AGENTS.md` for the repository's shared engineering workflow, issue tracker,
domain documentation rules, and skill inventory. The Claude-specific commands
and skills live under `.claude/`.

When a workflow skill points to `CONTEXT.md`, `docs/adr/`, or `docs/agents/`,
read those files before acting. Keep changes scoped to the user's request and
leave unrelated worktree changes untouched.
